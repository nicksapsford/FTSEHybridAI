COMMON ISSUES
-------------

Q: Arthur keeps saying STAY_OUT even on good setups.
A: Check Morgan confidence score. If <25, conservative mode is ON (hard rule).
   Also check kill switch status. After losses, Lancelot enforces cooldown.

Q: No trades for a long time.
A: Check session phase -- only MORNING_PRIME and AFTERNOON allow entries.
   Check calendar -- BoE decision days block 30 min either side of 12:00.
   Check daily SSL cloud direction -- it must match 1h SSL for entry.

Q: IG connection fails.
A: Check .env credentials. IG API can have session timeouts.
   ig_connector.py has 60s price caching to reduce API calls.
   Paper trading mode works without IG connection (yfinance fallback).

Q: Dashboard not loading.
A: Start dashboard_ftse.py in a separate terminal.
   Main loop and dashboard are separate processes.
   Dashboard port 5042 must not be in use.

Q: Force close not happening.
A: Force close checks every 30 seconds in position monitoring loop.
   It triggers at 16:20 UK -- Lancelot also blocks new entries at 15:30.
   Check UK timezone conversion -- pytz must be installed.
